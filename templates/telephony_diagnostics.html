Налаштування webhook в ElevenLabs

URL webhook у вас уже правильний. Але для дзвінків AI-агента недостатньо галочки «Transcription completed» у Developers — це інша подія (Speech-to-Text API). Потрібен окремий крок у налаштуваннях агентів.

  1. Webhook endpoint (у вас вже є) — Developers → Webhooks. URL: {{ webhook_url }} — залиште як є, ENABLED.
  2. Post-call webhook для агентів — відкрийте ElevenAgents → Settings → розділ Post-call webhooks → увімкніть і оберіть ваш webhook зі списку. Саме це надсилає подію post_call_transcription після дзвінка.

Після збереження зробіть тестовий дзвінок — транскрипція зʼявиться в картці ліда автоматично. Для старих дзвінків натисніть «Підтягнути транскрипцію» на сторінці ліда.

Швидка перевірка webhook

Запустіть на сервері, щоб перевірити endpoint ElevenLabs webhook:

curl -X POST "{{ webhook_url }}" \
-H "Content-Type: application/json" \
-d '{"type":"post_call_transcription","data":{"agent_id":"test","conversation_id":"conv_test","status":"done","conversation_initiation_client_data":{"dynamic_variables":{"lead_id":"1"}},"transcript":[{"role":"agent","message":"Вітаю"},{"role":"user","message":"Тест"}]}}'
